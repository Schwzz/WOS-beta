# Auralis Desktop delivery and review

## Scope

Implemented the approved independent Desktop app and full Desktop chat controls, plus Ctrl+B in the terminal footer and reduced spacing between terminal messages. Based on main after PR #4 was merged (5979dce).

## Delivered behavior

- A normal pywebview window with native dragging, resizing, minimize, maximize and close; no pin, always-on-top mode, or custom resize handle. Geometry saved separately in data/desktop_window.json.
- Shared ApplicationRuntime owns the Session, one speaker and local authenticated server; Desktop never imports the terminal input loop or waits for a terminal. run.bat/run-desktop.bat use pythonw; run-terminal.bat launches Terminal only. Errors under pythonw appear in a Windows dialog and local log.
- Chat-first interface with collapsible saved chats, New/Switch/Rename/Delete/Clear, explicit destructive confirmations, character selection, provider/model discovery, masked local key setup, voice toggle and Stop, and an optional existing avatar panel.
- Keys save atomically to ignored local .env; API responses report configuration status only. Existing comments/unrelated entries survive. Literal keys with interpolation syntax are rejected so dotenv cannot silently alter them after a restart.
- Both interfaces use the same file formats and settings. A project ownership lock prevents simultaneous writers. Closing suppresses late audio and discards replies that finish after shutdown; pending mutation ownership is retained until it is safe to release. Provider HTTP itself is not aborted.
- Drafts survive navigation and errors; stale mutations are rejected. Web history retries after transient failures.

## Review corrections

Independent review identified two introduced defects; both were reproduced and fixed with regression coverage:

1. A shutdown/reopen race could release ownership while an older reply was still committing. Session persistence commits now synchronize with close, and runtime ownership stays held until active backend commands finish. Closing rejects queued mutations and does not wait for the model HTTP request.
2. Two character definitions with the same display name caused the wrong selection to appear. Backend state and the shared frontend now carry character_id; the picker uses the unique ID. The JS regression intentionally uses duplicate names.

Root integration also adjusted the terminal fixture to create a fresh Session after its runpy-launched application has exited; changed launcher assertions to the new contract; and checked credential interpolation rejection.

## Remaining fixes and improvements

- **High: recoverable chat/index commits.** Existing core/conversation.py update_chat writes the chat before its index; Session rollback after an index-save failure can discard a saved exchange on a later write. API snapshots preserve live state but do not make multi-file persistence transactional. This existing finding is not fixed by Desktop.
- **High: corrupt-index recovery.** Existing load_index returns an empty list on malformed/unreadable data. A later mutation can replace the index and hide old chat files. Preserve/rebuild damaged indexes before mutation. See the earlier Auralis review for reproductions of both persistence findings.
- **Windows native smoke test.** CI fakes the native window host; a real Windows machine should verify pythonw launch/errors, WebView2, title-bar controls, DPI, geometry restoration, close during generation, and audio.
- **Request cancellation/deadlines.** Stop cancels/suppresses speech. A model request already submitted may continue server-side even after shutdown. Add explicit provider cancellation/consistent deadlines as a separate change.
- **Credential storage.** Local .env matches existing setup but is not encrypted vault storage. OS-backed credential storage and an explicit Remove key action are possible future improvements.
- **Legacy shell helpers.** Internal overlay names and unused legacy shell helper methods remain for compatibility/tests. They can be removed in a later cleanup after downstream callers migrate.
